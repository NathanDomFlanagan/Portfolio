Password Tester App

Problem

Password strength meters usually just check length and character variety - they don't tell you whether a password has actually been leaked in a real breach.

Approach

Built a desktop checker that combines local complexity checks with a real breach lookup against the Have I Been Pwned database, using k-anonymity so only the first 5 characters of a locally-hashed password ever leave the machine - never the password itself.

Result

A strength check that's actually grounded in real breach data, plus a generator that produces cryptographically secure passwords via Python's secrets module.

file-organiser

Problem

Approach
